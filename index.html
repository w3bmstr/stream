Android Camera → PC (WebRTC)

How to use (manual signaling – works on GitHub Pages):
1. On phone: choose “Camera Sender”, Start Camera → Create Offer → Copy → send the text to the PC (chat, email, etc.).
2. On PC: choose “Viewer”, paste the offer → Create Answer → Copy → send the answer back to the phone.
3. On phone: paste the answer → Set Remote Answer. Video should appear on the PC.
