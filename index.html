Sources, mix, EQ, and record — in one place.

Simple service workflow: open a camera, shape sound on the mixer/EQ, cut between sources, and record to a file. Hardware panels (GoStream, Fomako, Peavey PV10BT) stay available as control surfaces for planning and practice.

Works now: laptop / UVC USB webcams · mic through EQ + mixer · multi‑cam cut/fade · local recording · session presets.
Needs extra gear/software: USB security cams that are not webcams · RTSP IP cams · RTMP/NDI/HDMI switchers.

IP / security camera (network)
Browsers can show HTTP MJPEG / snapshot. Many security cams use RTSP (rtsp://192.168.1.72:554/…), which Chrome cannot play directly — use HTTP path from the camera manual, or enter a full custom URL.
